# Auditoría legal y de procedencia — V33

## Comprobaciones realizadas

- Reglamento (CE) 1223/2009: se mantiene como fuente jurídica principal. EUR-Lex muestra como versión consolidada actual la de 18/05/2026.
- CosIng: se mantiene únicamente como fuente informativa; la Comisión Europea indica expresamente que no tiene valor jurídico.
- Open Beauty Facts: se trata como fuente de datos de producto aportados por la comunidad, no como autoridad regulatoria.
- Licencias de Open Facts: se documentan ODbL, Database Contents License y CC BY-SA para imágenes según la documentación oficial; la reutilización concreta deberá cerrarse antes de producción.

## Decisiones de producto

V33 no permite que una diferencia entre OCR y base externa genere automáticamente una acusación de incumplimiento, falsificación, cambio de fórmula o error de etiquetado.

La comparación solo informa de diferencias en los datos disponibles.

## Privacidad

La fotografía permanece en el flujo OCR local del prototipo. La comparación usa el texto OCR ya extraído y el INCI que la ficha externa ya proporciona; no se envía la fotografía a Open Beauty Facts para realizar esta comprobación.
