# DESINZI · ZERO HUMO — V44 Release Candidate

Fecha: 04/10/2026

## Objetivo

V44 corrige una incoherencia de versionado detectada durante la auditoría posterior a V43. No se considera aceptable que una interfaz o una prueba interna anuncie una versión distinta de la versión realmente liberada.

## Correcciones

- Aplicación: `0.44.0`.
- Base de conocimiento: `2026.10.04-013`.
- Esquema de conocimiento: `4`.
- Backend: `0.8.0`.
- La autodiagnosis de la aplicación comprueba `0.44.0`.
- La autodiagnosis comprueba la base `2026.10.04-013`.
- El payload y el manifiesto conservan la misma versión de conocimiento.
- La vigilancia científica SCCS continúa separada de la situación jurídica.

## Criterio de auditoría

Una versión no se da por correcta solo porque el código arranque. También debe existir coherencia entre código, datos, manifiesto, backend y pruebas.

## Base legal de referencia

El motor regulatorio se mantiene vinculado al Reglamento (CE) 1223/2009 y sus modificaciones aplicables. La revisión actual incorpora, entre otras, la modificación de 2026/909, que figura como vigente en EUR-Lex.
