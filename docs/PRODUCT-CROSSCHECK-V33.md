# DESINZI · ZERO HUMO — V33

## Objetivo

Comparar el INCI obtenido mediante OCR de una fotografía de la etiqueta con el INCI recuperado de una ficha externa de Open Beauty Facts, sin convertir la diferencia en una acusación o conclusión jurídica.

## Reglas de seguridad

- Coincidencia textual exacta: se informa como tal.
- Nombres equivalentes solo se agrupan cuando la base de conocimiento verificada los identifica como el mismo ingrediente o alias.
- Una coincidencia aproximada no se utiliza para declarar equivalencia.
- Los elementos no identificables permanecen separados.
- Una diferencia no demuestra por sí sola cambio de fórmula, error de etiquetado, incumplimiento ni fraude.
- La ficha externa es una fuente de datos de producto, no una certificación regulatoria.
- No se modifica la ficha externa ni se envían fotografías de la persona usuaria a Open Beauty Facts en esta función.

## Procedencia y actualidad

Open Beauty Facts utiliza el mismo código base que Open Food Facts y dispone de una base específica para cosméticos. Su documentación indica que los datos son aportados voluntariamente y que no hay garantía de exactitud, integridad o fiabilidad. La API v3 es la recomendada para nuevas integraciones.
